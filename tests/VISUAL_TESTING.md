# Monolith Umbra visual testing

Use `Monolith Umbra Test Note.md` in an Obsidian test vault. Repeat the matrix
for Umbra, Resolarized, Glacier, Monolith, and Hunter in dark and light modes.

## Note views

- [ ] Source mode
- [ ] Live Preview
- [ ] Reading view
- [ ] Narrow desktop pane
- [ ] Phone-sized/mobile layout
- [ ] Print preview

## Application surfaces

- [ ] File explorer, search, bookmarks, backlinks, and properties
- [ ] Settings, menus, command palette, modal, prompt, and notice
- [ ] Canvas with text, file, link, and grouped cards
- [ ] Bases table and cards views
- [ ] Graph view
- [ ] Tabs, title bar, ribbon, status bar, and sidebars

## States

- [ ] Keyboard focus is visible
- [ ] Hover and active states remain legible
- [ ] Selected text, tags, navigation, and code remain distinct
- [ ] Disabled controls remain recognizable
- [ ] Success, warning, and error colors have adequate contrast
- [ ] Tables scroll and remain usable in narrow panes
- [ ] All checkbox icons render in editor and reading view
- [ ] Highlights have complete borders across wrapped lines
- [ ] Inline and display math do not collide with surrounding text

Record Obsidian and theme versions with each screenshot baseline. Screenshots
are intentionally not committed until captured from the real application.
